## 📌 Project Overview

This project is an interactive Power BI dashboard built using the **AdventureWorks** dataset.

The objective of this project is to transform raw sales data into meaningful business insights through data modeling, DAX measures, interactive visualizations, and custom report tooltips.

The dashboard enables users to explore sales performance, product categories, territories, and order metrics dynamically.
